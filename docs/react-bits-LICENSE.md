React Bits — https://github.com/DavidHDev/react-bits

BlurText, Magnet and TiltedCard in this portfolio are adapted
from or inspired by React Bits. The implementations use CSS and Pointer Events
instead of Motion, preserve the portfolio's styling, and respect reduced motion.

Upstream sources:
- https://reactbits.dev/text-animations/blur-text
- https://reactbits.dev/animations/magnet
- https://reactbits.dev/components/tilted-card
